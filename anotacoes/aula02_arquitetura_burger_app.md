# Aula 02 - Arquitetura do Burger App

## Aplicacao de estudo

Sistema web de hamburgueria desenvolvido em Python.

Tecnologias apresentadas:
- Python
- Flask
- Jinja
- Arquitetura orientada a microservicos
- Separacao inspirada em MVC

## Microservicos

### 1. Authentication Service
Responsavel pela autenticacao dos usuarios.

### 2. User Service
Responsavel pelo cadastro e gerenciamento de usuarios.

### 3. Product Service
Responsavel pelo gerenciamento de produtos.

### 4. Order Service
Responsavel pelo gerenciamento de pedidos.

## Organizacao arquitetural

Controllers:
Recebem requisicoes e controlam rotas.

Models:
Representam as entidades e os dados.

Services:
Contem a logica de negocio.

Templates:
Representam as interfaces HTML renderizadas pelo Jinja.
