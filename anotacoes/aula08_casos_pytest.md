# Aula 08 - Diferentes casos de teste com Pytest

## Funcao estudada
serialize_user(user)

## Microservico
auth-service

## Cenarios
1. Usuario completo.
2. Usuario incompleto.
3. Dicionario vazio.
4. Inteiro invalido.
5. String invalida.
6. Valores inesperados.

## Conceitos
- assert
- pytest.raises
- Entradas validas e invalidas
- Valores padrao
- Testes de regressao
- Execucao detalhada com pytest -v

## Observacao
O teste de valores inesperados documenta o
comportamento atual do serializador.

Ele nao representa validacao de dados de cadastro.
